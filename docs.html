Tài Liệu & Hướng Dẫn Sử Dụng Zefoy Automation API

Hệ thống tự động hóa tăng tương tác TikTok (Favorites, Views, Hearts) trên nền tảng Zefoy, tích hợp giải Captcha thông minh AI, xử lý nền bất đồng bộ và chống lỗi 502.

Base URL: https://zefoy-oayb.onrender.com
Format: JSON / HTTP REST
Key Auth: VIP License (sangdev.online)

⚙️ Cách Hệ Thống Hoạt Động (Architecture & Lifecycle)

Quy trình xử lý từ khi bạn gọi API đến khi bot gửi tương tác thành công vào video TikTok

01

📡 1. Tiếp Nhận Yêu Cầu

Client gửi HTTP request (dạng URL, Query string hoặc JSON). Server Gunicorn (4 threads) kiểm tra cú pháp và VIP License Key với máy chủ bản quyền sangdev.online.

02

⚡ 2. Khởi Chạy Bất Đồng Bộ

Hệ thống trả về JSON phản hồi ngay lập tức (dưới 5ms) thông báo bot đã nhận lệnh, đồng thời cấp phát một luồng ngầm độc lập (Daemon Thread) để xử lý việc cày tương tác.

03

🧩 3. Vượt Captcha Tự Động

Luồng bot tải ảnh Captcha từ Zefoy, dùng thuật toán RapidOCR nội bộ kết hợp NewOCR Web Cloud để nhận diện chữ chính xác và gửi giải mã chỉ trong ~0.2 giây.

04

🎯 4. Gửi Lệnh & Đếm Ngược

Bot gửi yêu cầu tăng (Favorites/Views) đến TikTok. Sau mỗi lượt gửi thành công, bot tự động trích xuất bộ đếm lùi (Timer) của Zefoy, ngủ chờ chính xác và tiếp tục vòng lặp 24/7.

✓ Cơ chế Non-Blocking
Mọi lệnh gọi API /run hoặc /api/{key}={url} không bao giờ làm treo kết nối mạng của bạn. Bot chạy trong nền và bạn có thể theo dõi tiến độ bất kỳ lúc nào qua API trạng thái hoặc Dashboard Web.

📋 Danh Sách Tham Số & Giá Trị Cần Thiết

Tất cả các tham số bạn cần chuẩn bị khi gửi lệnh tới bot

Tham Số Kiểu Dữ Liệu Bắt Buộc Mặc Định Mô Tả & Giá Trị Hợp Lệ
key String Bắt buộc — Mã VIP License Key được cấp từ Sang Dev. Ví dụ: VIP-X26Q-ES53-0EAC. Hệ thống sẽ xác thực bản quyền trước khi cho phép bot khởi chạy.
url String Bắt buộc — Đường link video TikTok mục tiêu cần tăng. Hỗ trợ mọi định dạng:
• https://www.tiktok.com/@user/video/7682004951563898132
• https://vt.tiktok.com/ZS.../
• https://vm.tiktok.com/.../
service String Tùy chọn Favorites Tên dịch vụ tương tác muốn tăng. Xem bảng dịch vụ bên dưới.
restart_if_running Boolean Tùy chọn true Nếu bot đang chạy video cũ, gửi yêu cầu mới sẽ tự động chuyển hướng sang video/dịch vụ mới mà không cần phải gọi /stop thủ công.

Python (requests) 
import requests

BASE_URL = "https://zefoy-oayb.onrender.com"
KEY = "VIP-X26Q-ES53-0EAC"
TIKTOK_URL = "https://www.tiktok.com/@fish_mc29/video/7682004951563898132"

# 1. Khởi chạy bot
run_res = requests.get(f"{BASE_URL}/run", params={
    "key": KEY,
    "service": "Favorites",
    "url": TIKTOK_URL
})
print("Start Bot:", run_res.json())

# 2. Theo dõi tiến trình
status_res = requests.get(f"{BASE_URL}/api/{KEY}")
data = status_res.json()
print(f"Trạng thái: {data.get('status')} | Timer: {data.get('timer')}s | Đã gửi: {data.get('total_sent')}")
JavaScript (Fetch API / Node.js) 
const BASE_URL = "https://zefoy-oayb.onrender.com";
const KEY = "VIP-X26Q-ES53-0EAC";
const VIDEO_URL = "https://www.tiktok.com/@fish_mc29/video/7682004951563898132";

// 1. Kích hoạt bot
async function startBot() {
    const res = await fetch(`${BASE_URL}/api/${KEY}=${encodeURIComponent(VIDEO_URL)}`);
    const data = await res.json();
    console.log("Response:", data);
}

// 2. Kiểm tra tiến độ
async function checkProgress() {
    const res = await fetch(`${BASE_URL}/api/${KEY}`);
    const state = await res.json();
    console.log(`Đang chạy: ${state.is_running}, Timer: ${state.timer}s, Sent: ${state.total_sent}`);
}

startBot();

🛡️ Hướng Dẫn Vận Hành 24/7 & Chống Lỗi 502 Bad Gateway

Các tiêu chuẩn kỹ thuật đã tối ưu hóa cho Render Free Tier

1. Gunicorn WSGI Đa Luồng (--workers 1 --threads 4)

Render Free có giới hạn bộ nhớ 512MB RAM. Nếu cấu hình nhiều Process Worker sẽ gây tràn RAM và bị Linux OOM Killer tắt tiến trình (nguyên nhân chính gây 502). Cấu hình 1 Worker với 4 Threads duy trì mức RAM ổn định chỉ ~120MB và phục vụ song song các lượt ping, gọi API mà không bị nghẽn.

2. Chống Ngủ Đông Bằng UptimeRobot (Khuyên Dùng)

Render Free tự động tắt máy chủ sau 15 phút nếu không có lượt truy cập từ bên ngoài. Khi có người truy cập lại, Render mất 50–90 giây để bật lại máy chủ, trong thời gian đó có thể xảy ra lỗi 502 Bad Gateway.

💡 Giải pháp giữ server luôn Online 24/7:
1. Truy cập UptimeRobot.com (Đăng ký miễn phí).
2. Tạo một Monitor loại HTTP(s).
3. Nhập URL: https://zefoy-oayb.onrender.com/ping.
4. Đặt chu kỳ kiểm tra: 5 phút một lần.
=> Render sẽ luôn nhận được tín hiệu HTTP và không bao giờ bị rơi vào trạng thái ngủ đông!
